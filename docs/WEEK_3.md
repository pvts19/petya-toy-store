# Неделя 3 — frontend и интеграция

## Итог недели

Frontend подключён к REST API и покрывает основной путь покупателя: просмотр каталога, поиск, фильтрацию, регистрацию, вход, корзину и оформление заказа.

## Реализованные экраны и блоки

| Блок | Возможности |
|---|---|
| Каталог | Карточки игрушек, цена, возраст, наличие |
| Поиск | Поиск по названию и описанию |
| Фильтры | Категория, возраст и сортировка |
| Авторизация | Регистрация, вход, выход, сохранение токена |
| Корзина | Добавление, удаление, подсчёт суммы |
| Оформление | Имя, телефон, адрес доставки |
| Заказы | История заказов текущего пользователя |
| Админ-панель | Добавление товара и изменение статуса заказа |

## Сквозной сценарий приёмки

1. Запустить backend и frontend.
2. Заполнить базу командой `python -m app.seed`.
3. Открыть каталог.
4. Найти игрушку через поиск или фильтр.
5. Зарегистрировать нового пользователя.
6. Добавить товар в корзину.
7. Заполнить данные доставки.
8. Оформить заказ.
9. Проверить заказ в истории пользователя.
10. Войти под администратором и изменить статус заказа.

## Приёмочные проверки

- гость может просматривать каталог, но при добавлении в корзину получает предложение войти;
- неверные данные входа показывают сообщение об ошибке;
- после регистрации пользователь автоматически может войти;
- товар нельзя заказать в количестве больше остатка;
- после оформления заказа остаток уменьшается;
- пользователь видит только собственные заказы;
- админ-панель недоступна обычному пользователю;
- каталог адаптируется под узкий экран.

## Известные ограничения учебной версии

- изображения товаров пока заменены простыми заглушками;
- онлайн-оплата не подключена;
- доставка и уведомления моделируются текстовыми полями и статусами;
- полноценная сборка требует установленного Node.js и запущенного Docker daemon.
