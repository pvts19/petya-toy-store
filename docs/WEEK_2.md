# Неделя 2 — backend и API

## Итог недели

Реализован основной backend интернет-магазина игрушек на FastAPI. Сервер умеет регистрировать пользователей, выдавать JWT, работать с каталогом, корзиной и заказами.

## Реализованные части

| Часть | Реализация |
|---|---|
| Пользователи | Регистрация, вход, получение текущего пользователя |
| Авторизация | JWT Bearer-токен, хеширование паролей |
| Категории | Просмотр, создание, изменение и удаление администратором |
| Товары | Просмотр каталога, поиск, фильтр по категории, создание и изменение администратором |
| Корзина | Добавление, изменение количества и удаление товаров |
| Заказы | Оформление заказа, сохранение состава и цены покупки |
| Остатки | Проверка наличия и уменьшение остатка после оформления |
| Администратор | Управление товарами и статусами заказов |

## API

```text
POST   /api/auth/register
POST   /api/auth/login
GET    /api/auth/me

GET    /api/categories
POST   /api/categories
PATCH  /api/categories/{id}
DELETE /api/categories/{id}

GET    /api/products
GET    /api/products/{id}
POST   /api/products
PATCH  /api/products/{id}
DELETE /api/products/{id}

GET    /api/cart
POST   /api/cart
PATCH  /api/cart/{product_id}
DELETE /api/cart/{product_id}

POST   /api/orders
GET    /api/orders
GET    /api/admin/orders
PATCH  /api/admin/orders/{id}
```

## Проверка прав

- публичными остаются каталог и категории;
- корзина и личные заказы доступны только авторизованному пользователю;
- каждый пользователь видит только свои корзину и заказы;
- административные маршруты проверяют роль `admin`;
- скрытый товар не показывается в публичном каталоге;
- заказ с количеством больше остатка отклоняется.

## Тестовые данные
